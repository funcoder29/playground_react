# React Playground

A collection of small, throwaway React experiments. I build one whenever a new React feature or technique lands, so I learn by trying it instead of only reading about it.

Each experiment lives in its own folder with its own README, dependencies and `npm run dev` script.

## Why This Repo Exists

- Keep up with React's updates as they release
- Learn by building tiny projects, breaking them on purpose and measuring the results
- Keep a personal changelog of what I tried, what surprised me and when I'd use each feature
